# SmsForwarder

برنامه فوروارد پیامک اندروید با فیلتر پیشرفته + پشتیبانی دو سیم‌کارت

## ویژگی‌ها
- فیلتر بر اساس شماره فرستنده (دقیق، شامل، شروع با، پایان با)
- فیلتر بر اساس محتوای پیامک
- شرط AND و OR بین فیلترها
- **انتخاب سیم‌کارت ۱ یا ۲** برای ارسال (مناسب گوشی‌های دو سیم)
- سازگار با اندروید ۱۴ و ۱۵ (Galaxy S22 Ultra و بالاتر)
- رابط کاربری فارسی و راست‌چین

## دانلود APK (خودکار از گیت‌هاب)

هر بار که کد آپدیت می‌شود، گیت‌هاب به صورت خودکار APK می‌سازد.

1. برو به تب **Actions** در همین ریپو:
   https://github.com/babakriazi/SmsForwarder/actions
2. آخرین workflow با نام **Build APK** را باز کن.
3. اگر سبز بود، پایین صفحه بخش **Artifacts** را پیدا کن و فایل **SmsForwarder-APK** را دانلود کن.

همچنین می‌توانی از منوی Actions دکمه **Run workflow** را بزنی تا دستی بیلد شروع شود.

## نصب
- فایل APK را به گوشی منتقل کن.
- اجازه نصب از منابع ناشناس را بده.
- بعد از نصب همه مجوزها (SMS + Phone) را بده.
- بهینه‌سازی باتری را برای برنامه غیرفعال کن (برنامه خودش پیشنهاد می‌دهد).

## نحوه استفاده
1. روی دکمه + بزن.
2. شرط‌های مورد نظرت را تنظیم کن.
3. سیم‌کارت مورد نظر برای ارسال را انتخاب کن.
4. شماره مقصد را وارد کن و ذخیره کن.

## هشدار
این برنامه فقط برای استفاده شخصی طراحی شده است.
