# SmsForwarder

برنامه فوروارد پیامک اندروید با فیلتر پیشرفته

## ویژگی‌ها
- فیلتر بر اساس شماره فرستنده (دقیق، شامل، شروع با)
- فیلتر بر اساس محتوای پیامک (شامل، دقیق، شروع/پایان با)
- شرط AND و OR بین فیلترها
- سازگار با اندروید ۱۴ و بالاتر (تست شده برای Galaxy S22 Ultra)
- رابط کاربری ساده و فارسی

## نحوه ساخت APK

1. این ریپو را Clone کنید یا به صورت ZIP دانلود کنید.
2. اندروید استودیو را باز کنید (نسخه جدید Hedgehog یا بالاتر).
3. **Open** را بزنید و پوشه پروژه را انتخاب کنید.
4. صبر کنید تا Gradle Sync کامل شود.
5. از منوی بالا: **Build → Build Bundle(s) / APK(s) → Build APK(s)**
6. بعد از اتمام، روی **locate** کلیک کنید تا فایل APK را ببینید.

فایل APK معمولاً در مسیر زیر قرار می‌گیرد:
`app/build/outputs/apk/debug/app-debug.apk`

## نصب
- فایل APK را به گوشی منتقل کنید.
- در تنظیمات، اجازه نصب از منابع ناشناس را بدهید.
- بعد از نصب، برنامه را باز کنید و تمام مجوزها (SMS و Notification) را بدهید.
- برای پایداری بیشتر، در تنظیمات باتری، برنامه را از بهینه‌سازی باتری مستثنی کنید.

## هشدار
این برنامه فقط برای استفاده شخصی است. گوگل پلی محدودیت‌های سختی روی برنامه‌های SMS دارد.
